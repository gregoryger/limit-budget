# Дизайн «Лимита»

Направление: демонстрация на хакатоне с рабочим финансовым сценарием. Сохраняем графитовую плавающую панель, боковое меню, стеклянные поверхности и жёлтую палитру исходного макета. Главный акцент — загрузка выписки и проверяемые цифры. Все существующие разделы остаются доступны.

## Визуальная система

- `src/ui/styles.css` — базовая раскладка существующих экранов; `src/ui/polish.css` — актуальные токены, типографика, поверхности, состояния и адаптивность.
- Onest для текста и цифр, Unbounded для заголовков страниц и бренда. Шрифты обслуживаются локально из `public/fonts`; лицензии OFL находятся рядом. Внешние запросы к Google Fonts не нужны.
- Жёлтый обозначает основное действие и свободные деньги; второстепенные действия остаются графитовыми. Демо-данные явно подписаны.
- На компьютере — плавающий кабинет; на планшете — узкое боковое меню; на телефоне — нижняя прокручиваемая навигация и сумма перед поясняющим текстом.
- Числа используют табличные цифры. Состояния фокуса, выделение текста, скроллбары и поля оформлены в общей палитре.

## Разбор бюджета на Remotion

`src/ui/motion/BudgetStory.tsx` — независимый, лениво загружаемый компонент на `remotion` и `@remotion/player` одной версии. Использует [официальный Player API](https://www.remotion.dev/docs/player/player).

Вход: `{ balance, obligations }`, целые копейки. Результат: визуальное объяснение `balance − obligations`. Будущие доходы сюда не входят. Итоговый прогноз показан отдельно, с учётом всех допущений приложения.

По умолчанию виден конечный результат. Кнопка «Как это считается» запускает разбор на 6 секунд; доступны пауза и повтор. Анимация не вызывает GigaChat, не изменяет данные и не подменяет арифметику приложения. При `prefers-reduced-motion` показывается статичный результат без кнопки воспроизведения; при скрытии вкладки проигрывание останавливается. Суммы доступны скринридеру как текст.

## Проверки

`npm run test:e2e` проверяет импорт, все разделы, ширины 320–1440 px, управление разбором, reduced motion и клавиатурное управление модальным окном. `tests/e2e/design.spec.ts` не требует ключа GigaChat.

Для демонстрации: откройте обзор, нажмите «Как это считается», затем «Проверить покупку». Чтобы показать основной сценарий обработки выписки, используйте «Попробовать демо» либо загрузите `public/demo-statement.csv`.
